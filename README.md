# InternPilot AI

Invite-only internship and early-career discovery assistant. Registration is open to people from any school or background, but new accounts require a unique code generated by the owner.

## Job discovery

The project includes 71 configured public job-board endpoints across 69 employer names, covering Greenhouse, Lever, Ashby and Workday. The app refreshes sources on a schedule and can also be refreshed manually. A single source failure does not interrupt other sources, and stale listings are retired only after that specific board refreshes successfully.

See [JOB_DISCOVERY_SETUP.md](JOB_DISCOVERY_SETUP.md) for employer coverage, setup, health checks, and limitations.

## Local development

See [NEXT_STEPS.md](NEXT_STEPS.md) for the original local setup and [JOB_DISCOVERY_SETUP.md](JOB_DISCOVERY_SETUP.md) for the new source refresh commands.

Applications are always completed on the employer's own career site. InternPilot does not submit applications automatically.
